# Source

These folders contain headers and built flite library files that I cross compiled from flite source - see https://github.com/festvox/flite

All of these libraries are licensed under Flite's BSD-like licensing - please see the original repository, or the licenses under `flite/licenses`.

I have copied these library files to simplify the build instructions for this extension

However, if you wish to use more of flite's libraries, I encourage the user to build and link from the source respository which is well documented.
